# Xtools
**Xtools** is an offline-first creator toolkit developed by **LiyX**.
The first module is **Voice Studio**, designed to generate high-quality voiceovers for creators, podcasters, students, teachers and businesses.

## Vision
Build a professional creator toolkit that works offline, is lightweight, fast and expandable.

## Current Module
- Voice Studio

## Future Modules
- AI Writer
- PDF Reader
- OCR Scanner
- Subtitle Creator
- Image Tools
- Creator AI
